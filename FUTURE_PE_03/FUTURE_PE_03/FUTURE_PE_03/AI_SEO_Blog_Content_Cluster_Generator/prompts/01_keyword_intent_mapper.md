# Prompt 01 — Keyword & Search Intent Mapper

## Copy/Paste Prompt

You are an SEO strategist creating a keyword and search-intent map for a business website.

BUSINESS:
- Business type: [BUSINESS TYPE]
- Business name: [BUSINESS NAME]
- Location: [CITY, REGION, COUNTRY]
- Main services: [SERVICES]
- Target audience: [AUDIENCE]
- Primary conversion: [CALL / FORM / BOOKING / PURCHASE]

TASK:
Create a keyword strategy around [MAIN TOPIC].

For each keyword/topic provide:
1. Keyword
2. Search intent
3. Funnel stage: TOFU / MOFU / BOFU
4. Suggested page type
5. Primary or secondary keyword
6. Suggested content angle
7. Internal-link destination
8. Conversion opportunity

Rules:
- Do not invent search volume or keyword difficulty.
- If data is unavailable, mark it as "Needs tool validation".
- Avoid keyword stuffing.
- Separate informational, commercial and transactional intent.
- Prioritize topics that match the actual business services.
- Identify possible local modifiers such as city, neighborhood or service + city.
- Flag any topic that requires expert fact-checking.

Return the result as a clean markdown table.
