# SEO Publishing Checklist

## Before Writing

- [ ] Business and audience defined
- [ ] Primary keyword selected
- [ ] Search intent identified
- [ ] SERP manually reviewed
- [ ] Existing website pages checked
- [ ] Content overlap checked

## On-Page SEO

- [ ] One clear H1
- [ ] Logical H2/H3 structure
- [ ] Primary topic addressed naturally
- [ ] Helpful introduction
- [ ] Short paragraphs
- [ ] Descriptive subheadings
- [ ] Relevant internal links
- [ ] Relevant CTA
- [ ] Meta title drafted
- [ ] Meta description drafted

## Quality

- [ ] No keyword stuffing
- [ ] No fabricated statistics
- [ ] No fake testimonials
- [ ] No unsupported claims
- [ ] No unnecessary repetition
- [ ] Human-readable
- [ ] Original angle/value added
- [ ] Facts reviewed

## Local SEO

- [ ] City/service wording is natural
- [ ] Service area is accurate
- [ ] No fake local references
- [ ] Contact/location information is current
- [ ] Local CTA is clear

## Final Review

- [ ] Business owner approved
- [ ] Subject-matter expert reviewed high-risk claims
- [ ] Links tested
- [ ] Formatting checked on mobile
- [ ] Images have useful alt text
